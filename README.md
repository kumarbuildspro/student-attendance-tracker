# 📋 Attendance Tracker PWA

A fast, responsive, and installable Progressive Web Application (PWA) built with vanilla web technologies to manage school and coaching institute student attendance.

---

## 🛠️ Tech Stack & Files Structure

This project is built using:

* **`index.html`** - The primary HTML layout containing UI structures for adding students, buttons, and summary counts.
* **`style.css`** - Clean and modern CSS styling designed specifically for mobile and desktop screens.
* **`script.js`** - Contains all dynamic functionality (adding/deleting students, toggling Present/Absent status, and LocalStorage management).
* **`manifest.json`** - Web App Manifest configuration that enables app installation, defines app icons, theme colors, and display mode.
* **`sw.js`** - Service Worker script enabling offline usage and resource caching.
* **`README.md`** - Project documentation and setup guide.

---

## 🌟 Key Features

* **Quick Attendance Logging:** Mark students as Present (P) or Absent (A) with a single click.
* **Offline Functionality:** Service Worker keeps the application working smoothly even without internet.
* **Installable PWA:** Easily install on Android, iOS, or PC desktop using Google Chrome's "Add to Home Screen" option.
* **Local Data Storage:** Uses browser LocalStorage so data remains saved even when refreshing or closing the browser.

---

## 📱 How to Install

1. Open the hosted GitHub Pages URL in **Google Chrome**.
2. Tap on the browser's **3-dot menu**.
3. Select **"Install App"** or **"Add to Home Screen"**.
4. Launch it directly from your device home screen like a native mobile app.
